Crop Price Forecasting Project - Step by Step Run Guide

Start from Statistical Modeling

Assumption:
- You already have the cleaned data ready at data/processed/clean_prices.csv
- Or you already converted raw JSON downloads into data/parquet/ partitions

1. Activate the virtual environment

   .\.venv\Scripts\activate

2. Start with statistical modeling

   python notebooks/02_statistical_models.py --crop "Tomato" --state "Tamil Nadu"

   Output:
   - notebooks/statistical_outputs/
   - model saved in models/
   - baseline scores saved for comparison

3. Train the XGBoost model

   python notebooks/03_ml_models.py --crop "Tomato" --state "Tamil Nadu"

   Output:
   - XGBoost model saved in models/
   - forecast CSV and chart saved in notebooks/ml_outputs/

4. Train the LSTM model

   python notebooks/04_lstm_model.py --crop "Tomato" --state "Tamil Nadu"

   Output:
   - LSTM model saved in models/
   - forecast CSV and chart saved in notebooks/ml_outputs/

5. Retrain the full stack with ensemble and drift logging

   python run_pipeline.py --train --crop "Tomato" --state "Tamil Nadu"

   Output:
   - ARIMA, XGBoost, LSTM, and ensemble models saved in models/
   - forecast logs saved in data/prediction_logs.duckdb
   - drift report computed during retraining

6. Run the FastAPI service

   uvicorn api.main:app --reload

   Useful endpoints:
   - GET /health
   - GET /forecast?crop=Tomato&state=Tamil%20Nadu&model=ensemble&steps=30
   - GET /explain?crop=Tomato&state=Tamil%20Nadu&model=ensemble
   - GET /advisory?crop=Tomato&state=Tamil%20Nadu&model=ensemble
   - GET /series?crop=Tomato&state=Tamil%20Nadu
   - GET /history
   - GET /monitoring?crop=Tomato&state=Tamil%20Nadu

7. Run the Streamlit dashboard

   streamlit run app/streamlit_app.py

   Use the dashboard to:
   - choose ARIMA, XGBoost, LSTM, or ensemble
   - generate forecasts
   - inspect SHAP explanations for XGBoost or ensemble
   - save forecast logs for drift analysis
   - review recent prediction history and drift summary

8. Optional: refresh the data pipeline

   python -m src.data.download_data
   python -m src.data.json_to_parquet --resume

   Then rerun the retraining pipeline:
   python run_pipeline.py --train --crop "Tomato" --state "Tamil Nadu"

9. Optional: run the weekly automation locally

   The GitHub Actions workflow is in:
   .github/workflows/weekly_retrain.yml

   It performs:
   - download latest data
   - convert JSON to Parquet
   - retrain the model stack

Recommended order for a fresh project run:
1. 02_statistical_models.py
2. 03_ml_models.py
3. 04_lstm_model.py
4. src.mlops.retrain_pipeline
5. api.main
6. app.streamlit_app
